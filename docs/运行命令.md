# 终端1 — AI 服务（[8081](http://localhost:8081/)）
**ai-services板块运行命令**
```
cd ai-services
pip install -r requirements.txt
cp .env.example .env（首次需要）
python main.py
```

# 终端2 — 前端服务（[5173](http://localhost:5173/)）
**frontend板块运行命令**
```
cd frontend
npm install
npm run dev
```

# 终端3 — Java 后端（[8080](http://localhost:8080/)）：
**backend板块运行命令**
```
cd backend
$env:SPRING_PROFILES_ACTIVE="dev"; mvn spring-boot:run
```
