## 一、平台简介

### 1.1 平台概述

元景万悟平台是中国联通推出的**企业级多租户AI智能体开发平台**，基于Apache 2.0开源协议，为企业提供从智能体开发、工作流编排到知识库管理的一站式AI解决方案。

**核心定位**：
- 企业级AI中台，支持低代码/无代码构建智能应用
- 多租户架构，满足数据安全隔离和成本控制需求
- 信创适配，支持国产操作系统和数据库

### 1.2 核心功能模块

| 模块 | 功能描述 |
|-----|---------|
| **模型管理** | 支持多种AI模型导入和统一管理 |
| **知识库** | 文档解析、向量化、检索增强（RAG） |
| **智能体** | 通用智能体开发与Skills编排 |
| **工作流** | 可视化工作流编排 |
| **MCP广场** | 支持导入并使用不同服务商的MCP协议 |
| **权限管理** | 多租户权限控制 |

### 1.3 支持的模型类型

| 模型类型 | 支持能力 |
|---------|---------|
| 文本生成（LLM） | 智能对话、内容创作、摘要生成 |
| 文本向量化（Embedding） | 语义检索、相似度计算 |
| 多模态向量化 | 图像、语音等多模态数据处理 |
| 文本重排序（Reranker） | 搜索结果重排序优化 |
| OCR | 图像文字识别 |
| GUI | 图形用户界面生成 |

## 二、快速开始

### 2.1 环境要求

- **硬件**：至少8核CPU、32GB内存、200GB硬盘空间
- **软件**：Docker、Docker Compose

### 2.2 部署步骤

```bash
# 1. 克隆代码
git clone https://github.com/UnicomAI/wanwu.git
cd wanwu

# 2. 创建网络
docker network create wanwu-network

# 3. 启动服务
docker-compose up -d

# 4. 访问平台
# 地址：http://localhost:8081
# 默认账号：admin / Wanwu123456
```

### 2.3 获取API凭证

1. 登录平台后，进入 **个人设置** → **API密钥管理**
2. 点击 **创建API密钥**，记录生成的 `API Key` 和 `API Secret`
3. 在代码中使用 `Authorization: Bearer <api-key>` 进行认证

## 三、API认证与授权

### 3.1 认证机制

平台采用 **JWT（JSON Web Token）** 认证机制：

```bash
# 获取Token
curl -X POST http://localhost:8081/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "Wanwu123456"
  }'
```

### 3.2 请求头规范

```
Authorization: Bearer <jwt-token>
X-Language: zh-CN
X-Org-Id: org-123456
X-Client-Id: web-client
```

### 3.3 统一响应格式

```json
{
  "code": 0,
  "data": {},
  "msg": "操作成功"
}
```

## 四、核心API使用

### 4.1 智能体对话API

**创建智能体**：

```bash
curl -X POST http://localhost:8081/api/v1/agent \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "云盘助手",
    "description": "基于大模型的智能云盘助手",
    "model": "yuanjing-70b-chat",
    "knowledgeBaseIds": ["kb-001"],
    "workflowId": "wf-001"
  }'
```

**智能体对话**：

```bash
curl -X POST http://localhost:8081/api/v1/agent/{agentId}/chat \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "帮我整理一下上周的工作文档",
    "sessionId": "session-001",
    "stream": false
  }'
```

### 4.2 知识库API

**创建知识库**：

```bash
curl -X POST http://localhost:8081/api/v1/knowledge \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: multipart/form-data" \
  -F "name=云盘知识库" \
  -F "description=存储云盘文件的知识库" \
  -F "files=@document.pdf"
```

**知识库问答**：

```bash
curl -X POST http://localhost:8081/api/v1/knowledge/{knowledgeId}/qa \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "公司报销政策有哪些规定？",
    "topK": 5,
    "scoreThreshold": 0.7
  }'
```

### 4.3 模型API

## 九、代码示例

### 9.1 Python SDK使用

```python
import requests

class WanwuClient:
    def __init__(self, api_key, base_url="http://localhost:8081"):
        self.api_key = api_key
        self.base_url = base_url
        self.headers = {
            "Authorization": f"Bearer {api_key}",
            "Content-Type": "application/json"
        }
    
    def chat(self, agent_id, message, session_id=None):
        url = f"{self.base_url}/api/v1/agent/{agent_id}/chat"
        data = {
            "message": message,
            "sessionId": session_id or "default",
            "stream": False
        }
        response = requests.post(url, headers=self.headers, json=data)
        return response.json()
    
    def create_knowledge(self, name, files):
        url = f"{self.base_url}/api/v1/knowledge"
        data = {
            "name": name,
            "files": files
        }
        response = requests.post(url, headers=self.headers, json=data)
        return response.json()

# 使用示例
client = WanwuClient(api_key="sk-xxx")
result = client.chat("agent-001", "帮我整理一下文件")
print(result)
```

### 9.2 Java SDK使用

```java
import okhttp3.OkHttpClient;
import okhttp3.Request;
import okhttp3.RequestBody;
import okhttp3.Response;

public class WanwuClient {
    private String apiKey;
    private String baseUrl;
    private OkHttpClient client;
    
    public WanwuClient(String apiKey) {
        this.apiKey = apiKey;
        this.baseUrl = "http://localhost:8081";
        this.client = new OkHttpClient();
    }
    
    public String chat(String agentId, String message) throws Exception {
        String url = baseUrl + "/api/v1/agent/" + agentId + "/chat";
        String json = String.format(
            "{\"message\": \"%s\", \"sessionId\": \"default\", \"stream\": false}",
            message
        );
        
        RequestBody body = RequestBody.create(json, 
            okhttp3.MediaType.parse("application/json"));
        Request request = new Request.Builder()
            .url(url)
            .header("Authorization", "Bearer " + apiKey)
            .post(body)
            .build();
        
        try (Response response = client.newCall(request).execute()) {
            return response.body().string();
        }
    }
}
```

### 9.3 流式响应处理

```python
import requests

def stream_chat(api_key, agent_id, message):
    url = f"http://localhost:8081/api/v1/agent/{agent_id}/chat"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json"
    }
    data = {
        "message": message,
        "sessionId": "default",
        "stream": True
    }
    
    response = requests.post(url, headers=headers, json=data, stream=True)
    for chunk in response.iter_lines():
        if chunk:
            print(chunk.decode('utf-8'))

# 使用示例
stream_chat("sk-xxx", "agent-001", "请详细介绍一下项目")
```

## 十、常见问题

### 10.1 平台部署问题

**Q**：容器启动失败？

**A**：检查Docker资源是否充足，至少需要8核CPU和32GB内存。可以通过以下命令检查：

```bash
docker logs <container-name>
```

### 10.2 API调用问题

**Q**：API返回401未授权？

**A**：检查Authorization请求头是否正确，确保Token未过期。可以重新获取Token：

```bash
curl -X POST http://localhost:8081/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "Wanwu123456"}'
```

### 10.3 模型调用问题

**Q**：模型调用超时？

**A**：对于长文本生成，建议使用流式响应（`stream: true`），并调整超时时间：

```python
response = requests.post(url, headers=headers, json=data, 
                        stream=True, timeout=120)
```

### 10.4 知识库问题

**Q**：文档上传失败？

**A**：检查文件大小限制（默认100MB），支持的文件格式包括PDF、Word、Markdown、图片等。

### 10.5 性能问题

**Q**：检索响应慢？

**A**：优化索引配置，调整分块大小和向量索引类型。建议使用HNSW索引以提升检索速度。
