## 二、已修复问题

| 问题 | 原因 | 修复方式 |
|------|------|----------|
| 登录/退出白屏 | useSSE hook放在条件块内，违反React Hooks规则 | 移到条件外，hook内部处理未登录情况 |
| 文件上传500 | 数据库缺少列、大小写不匹配、jsonb类型不匹配 | 添加缺失列、CHECK约束改为大小写不敏感 |
| FileCard/FileDetail崩溃 | sensitiveLevel大小写不匹配导致bgColor读取undefined | 使用toLowerCase()转换并添加默认值 |
| 文件上传状态模拟 | 使用setTimeout模拟进度 | 改为真实axios onUploadProgress监听 |
| Docker拉取卡住 | 代理配置问题 | 配置国内镜像源，手动拉取镜像 |

### 3.1 测试与运维工程师（当前 - 最高优先级）

#### 任务1：部署到阿里云 ECS（按实际服务器执行）

**准备工作**：
- 确保 ECS 服务器（`<ECS_SERVER_IP>`）已安装 Docker 24.x+

**部署步骤**：

```bash
# 1. 上传项目目录与部署文件（本机执行）
scp -r backend frontend ai-services docker-compose.prod.yml deploy docs/database/DDL脚本.sql docs/database/seed_data.sql root@<ECS_SERVER_IP>:/opt/nebulamind/

# 2. 登录 ECS
ssh root@<ECS_SERVER_IP>

# 3. 配置环境变量
mkdir -p /opt/nebulamind
cat > /opt/nebulamind/.env << 'EOF'
MAAS_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
JWT_SECRET=your-production-jwt-secret-key-must-be-at-least-32-bytes-long
INTERNAL_API_KEY=your-internal-api-key
EOF

# 4. 构建并启动服务
cd /opt/nebulamind
docker compose -f docker-compose.prod.yml up -d --build

# 5. 验证
docker ps
curl http://localhost:8080/api/v1/public/health
curl http://localhost:80
```

## 八、常见问题

- **部署后服务无法启动**：查看 `docker logs nebulamind-backend` 排查，检查数据库连接和MinIO状态
- **文件上传失败**：检查MinIO是否可访问、存储空间是否充足、文件是否超过100MB限制
- **AI服务调用失败**：检查 `MAAS_API_KEY` 是否正确配置，网络是否能访问元景MaaS平台
- **前端白屏**：检查Nginx配置和后端API是否正常响应
- **所有问题**：见 `DEPLOYMENT_GUIDE.md` 完整FAQ
