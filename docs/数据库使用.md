# 数据库与基础设施使用说明

## 1. Docker Compose 启动基础设施

仓库根目录的 `docker-compose.yml` 只编排基础设施（不含应用服务）；本地开发请使用：

```bash
docker compose -f docker-compose.dev.yml up -d
```

生产完整编排使用：

```bash
docker compose -f docker-compose.prod.yml up -d --build
```

启动的服务：

| 服务 | 端口 | 默认凭证 | 说明 |
|------|------|---------|------|
| PostgreSQL | 5432 | 数据库 `erDiagram` / 用户 `root` / 密码由 `POSTGRES_PASSWORD` 指定 | 业务数据库 |
| Redis | 6379 | 无密码 | 缓存 |
| RabbitMQ | 5672 / 15672 | `guest` / `guest` | 消息队列 |
| MinIO | 9000 / 9001 | `nebulamind` / `your-minio-password` | 对象存储 |
| etcd | 2379 | - | Milvus 元数据存储 |
| Milvus | 19530 / 9091 | - | 向量数据库 |

注意：`docker-compose.dev.yml` 中 `POSTGRES_PASSWORD` 为 `<your-password>` 占位符，使用前需在 `.env` 中配置。

## 2. 环境变量配置

更新 `.env.example`，包含统一的数据库配置：

```bash
# 数据库
DB_URL=jdbc:postgresql://localhost:5432/erDiagram
DB_USERNAME=root
DB_PASSWORD=change-me
```

使用前将 `.env.example` 复制为 `.env` 并填写真实值，切勿提交 `.env`。

## 3. 数据库初始化

PostgreSQL 容器启动时会自动执行：

- `docs/database/DDL脚本.sql`：建表语句
- `docs/database/seed_data.sql`：种子数据

包含用户表、文件表、文件内容表、文件版本表、语义索引表等核心表结构、索引与扩展（uuid-ossp、pg_trgm 等）。

## 4. 本地快速开始

```bash
# 1. 启动基础设施
docker compose -f docker-compose.dev.yml up -d

# 2. 启动后端
cd backend
mvn spring-boot:run -Dspring.profiles.active=dev

# 3. 启动前端（新终端）
cd frontend
pnpm install
pnpm run dev

# 4. 启动 AI 服务（新终端）
cd ai-services
pip install -r requirements.txt
python main.py
```

## 5. 手动连接数据库

- JDBC URL: `jdbc:postgresql://localhost:5432/erDiagram`
- 用户名: `root`
- 密码: 以 `.env` 中 `DB_PASSWORD` / `POSTGRES_PASSWORD` 为准
