### 1. Docker Compose 一键启动（推荐）
创建了 docker-compose.yml ，包含所有依赖服务：
启动的服务 ：
服务 端口 默认凭证 
PostgreSQL 5432 nebulamind / your-minio-password 
Redis 6379 无密码 
RabbitMQ 5672 nebulamind / your-minio-password 
MinIO 9000 nebulamind / your-minio-password

### 2. 环境变量配置
更新了 .env.example ，包含统一的数据库配置：
# 数据库
DB_URL=jdbc:postgresql://localhost:5432/nebulamind
DB_USERNAME=nebulamind
DB_PASSWORD=your-minio-password

### 3. 数据库初始化
DDL脚本会自动执行，包含：
- 用户表、文件表、文件内容表等核心表结构
- 所有必要的索引（13个索引）
- 扩展（uuid-ossp、pg_trgm、pg_stat_statements）

### 4. 快速开始
其他成员只需要：

```
# 1. 克隆仓库
git clone https://github.com/YL-snow/NebulaMind.git

# 2. 启动基础设施
cd NebulaMind
docker-compose up -d

# 3. 配置环境变量
cd backend
cp .env.example .env
# 编辑 .env 配置 MAAS_API_KEY

# 4. 运行项目
mvn spring-boot:run
```
### 5. 手动连接数据库
如果需要使用数据库工具连接：
- JDBC URL : jdbc:postgresql://localhost:5432/nebulamind
- 用户名 : nebulamind
- 密码 : your-minio-password
