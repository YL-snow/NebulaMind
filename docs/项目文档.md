# NebulaMind 星云智脑

---

## 项目简介

**NebulaMind（星云智脑）** 是一款基于大模型技术的智能云盘与文档管理平台，旨在解决个人及团队在文件管理、信息检索和内容生成中的效率瓶颈。

平台采用**双服务架构**：Java 21 + Spring Boot 3.2 构建后端服务，Python FastAPI 提供 AI 推理层，前端采用 React 19 + TypeScript + Vite。基础设施包括 PostgreSQL、Redis、RabbitMQ、MinIO 对象存储及 Milvus 向量数据库。

核心能力涵盖：AI 自动文件分类与标签、语义检索与问答（单文档/跨文档）、长文档摘要、格式转换、报告与 PPT 自动生成、敏感内容两级检测（正则 + LLM）+ AES-256-GCM 加密、文件版本追踪与 diff 对比。全流程 Docker 容器化，支持一键部署至阿里云 ECS。

---

## 项目核心成果

### 一、创新点

- **AI 驱动全流程文档处理**：从文件上传到自动分类、打标签、向量化索引、语义搜索，形成完整的"上传→理解→检索→生成"闭环，无需人工干预。
- **两级敏感内容检测**：正则快速筛查 + LLM 深度分析，兼顾性能与准确率，高风险文件自动触发 AES-256-GCM 加密。
- **跨文档整合问答（RAG）**：支持同时选择多个文件进行联合问答，基于 Milvus 向量库实现检索增强生成，突破单文档问答局限。
- **将云盘功能与大模型深度融合**：用户可直接基于网盘素材生成摘要、报告、PPT，或进行格式转换，而非传统网盘仅提供存储和预览。

### 四、应用案例

- **个人知识管理**：用户上传文档后，AI 自动分类打标签，支持语义搜索精准定位内容，可基于多文件生成读书报告或研究综述。
- **团队文档协作**：文件版本历史与 diff 对比支持修改追踪，敏感内容自动加密确保合规。
- **内容创作者**：基于云盘素材快速生成演示文稿（PPT）或分析报告，支持格式转换（txt/md → docx）。
- **企业文档安全**：两级敏感检测 + 自动加密机制可用于企业内部文档外发前的安全检查。
