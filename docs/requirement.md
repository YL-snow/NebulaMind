# 需求说明

## 项目名称

NebulaMind · 星云智脑（智能云盘与文档管理平台）

## 项目简介

NebulaMind 是一款面向个人及团队的智能云盘应用，将 AI 能力深度融入文件管理全流程。用户上传文档后，系统自动完成分类打标、向量索引、语义搜索、智能问答和内容生成，形成"上传 → 理解 → 检索 → 生成"的完整闭环。

## 用户画像

### 人物 A：个人知识工作者 — 小林

> "我电脑里存了几百份文档，找起来特别费劲，更别说整理归纳了。我想要一个能自动帮我分类、还能直接问文件内容的工具。"

- 年龄：25-40 岁
- 背景：咨询、研究、内容创作等知识密集型工作，每天处理大量文档
- 痛点：文件分散、检索困难、整理耗时、信息利用率低
- 期望：上传即自动分类，用自然语言就能找到文件，能基于文件内容直接得到答案

### 人物 B：研究团队负责人 — 王老师

> "团队文档都放在共享盘里，版本混乱、检索低效，成员之间协作靠口头沟通。"

- 年龄：35-55 岁
- 背景：高校课题组或企业研发团队管理者，需要管理多人共享文档
- 痛点：多人协作版本混乱、团队知识沉淀困难、敏感资料管控不足
- 期望：版本可追溯、成员权限可管控、团队知识可被检索和复用

### 人物 C：企业文档安全管理员 — 赵工

> "内部文档外发前要人工检查一遍有没有敏感信息，量大的时候根本忙不过来。"

- 年龄：30-45 岁
- 背景：企业 IT / 信息安全岗位，负责文档合规检查
- 痛点：敏感内容人工筛查效率低、存在漏检风险、缺少自动化手段
- 期望：自动检测敏感内容，高风险文件自动加密，减少人工干预

## 用户故事

### 优先级 P0（必须有）

| ID | 用户故事 | 验收标准 |
|----|---------|---------|
| US-001 | 作为用户，我想要注册并登录账号，以便安全地管理自己的文件 | 支持注册/登录/登出；JWT 认证；Token 过期自动续期 |
| US-002 | 作为用户，我想要上传和下载文件，以便在云盘中存储和取用文档 | 支持大文件分片上传、断点续传；下载内容与上传一致 |
| US-003 | 作为用户，我想要用自然语言搜索文件，以便快速找到目标文档 | 输入语义描述可返回相关文件；支持按相关度排序 |
| US-004 | 作为用户，我想要对文档进行 AI 问答，以便直接从文档中获取答案 | 单文档问答可返回基于内容的答案并标注来源；跨文档问答可聚合多个文件 |
| US-005 | 作为用户，我想要 AI 自动分类我的文件，以便减少手动整理成本 | 上传后自动生成分类标签；支持手动修正标签 |
| US-006 | 作为用户，我想要查看文件版本历史，以便追踪文档修改过程 | 展示版本列表、时间与操作者；支持版本 diff 对比 |

### 优先级 P1（应该有）

| ID | 用户故事 | 验收标准 |
|----|---------|---------|
| US-007 | 作为用户，我想要基于文件生成摘要和报告，以便快速提炼文档要点 | 输入文档可生成摘要、要点列表、结构化报告 |
| US-008 | 作为用户，我想要进行格式转换，以便在不同场景下使用文档 | 支持 txt/md → docx；转换后内容完整 |
| US-009 | 作为管理员，我想要管理用户权限，以便控制文件访问范围 | 支持角色配置与访问控制；权限变更即时生效 |
| US-010 | 作为团队负责人，我想要成员共享与协作编辑，以便团队共同管理文档 | 支持共享文件夹与成员权限设置；修改实时同步 |

### 优先级 P2（可以有）

| ID | 用户故事 | 验收标准 |
|----|---------|---------|
| US-011 | 作为安全管理员，我想要自动检测敏感内容，以便降低信息泄露风险 | 两级检测（正则 + LLM）可标记风险文件 |
| US-012 | 作为用户，我想要文件自动加密，以便保护高风险文档 | 高风险文件自动 AES-256-GCM 加密，解密权限受控 |
| US-013 | 作为用户，我想要将云盘挂载为网络驱动器，以便在本地直接操作文件 | 支持 WebDAV 协议；可读写常用文件 |
| US-014 | 作为开发者，我想要使用 S3 兼容接口，以便与外部工具集成 | 提供 S3 兼容 API；支持常用操作 |

## MoSCoW 优先级矩阵

| 分类 | 功能 | 理由 |
|------|------|------|
| **Must Have** | 用户认证、文件上传/下载、语义搜索、文档问答、智能分类 | 核心业务闭环，AI 云盘的差异化能力 |
| **Should Have** | 版本管理、摘要/报告生成、格式转换、权限管理 | 提升知识管理效率，属于第二优先级的核心体验 |
| **Could Have** | 敏感检测、自动加密、WebDAV、S3 兼容 | 安全合规与生态集成，可在 V1.2+ 迭代交付 |
| **Won't Have** | 移动端 App、实时多人协同编辑、云盘互备迁移 | 超出当前版本范围，纳入后续规划 |

## 功能模块

### 模块一：用户与认证
- 注册 / 登录 / 登出
- JWT 认证 + Refresh Token 自动续期
- 角色权限管理

### 模块二：文件管理
- 分片上传 / 断点续传 / 重复检测
- 文件版本历史与 diff 对比
- 智能分类与标签
- 多存储后端（MinIO/S3、本地、联通云盘预留）

### 模块三：AI 能力
- 语义搜索（向量检索）
- 单文档 / 跨文档 RAG 问答
- 摘要、要点、报告、PPT 生成
- 格式转换（txt/md → docx）

### 模块四：安全与合规
- 敏感内容两级检测
- 高风险文件自动加密
- 基于角色的访问控制

### 模块五：平台集成
- WebDAV 协议兼容
- S3 兼容接口
- WebSocket / SSE 实时通信

## 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 文件上传接口响应 < 1s；语义搜索 P95 < 2s；AI 问答流式响应 |
| 安全 | JWT + Refresh Token；BCrypt 密码加密；敏感文件 AES-256-GCM 加密 |
| 可用性 | 服务通过 Docker Compose 一键启动；关键路径有错误提示与重试 |
| 可扩展性 | 存储抽象层支持多后端；AI 服务与业务服务解耦 |
| 可观测性 | Sentinel 限流熔断；预留 SkyWalking 调用链追踪 |
