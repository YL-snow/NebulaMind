# NebulaMind 在线演示指南

本文档用于在面试或项目验收时完整演示 NebulaMind，覆盖主要功能链路和讲解要点。

## 演示流程

完整演示约 15-30 分钟，按下面顺序操作：

### 1. 注册与登录

1. 打开 Web 应用地址，进入注册页创建普通账号。
2. 使用新账号登录，进入文件管理首页。

讲解点：JWT 认证、刷新令牌自动续期、Spring Security 权限模型。

### 2. 上传多类型文件

1. 准备 3-5 个不同类型的文件，例如 `.txt`、`.md`、`.docx`、`.pdf`、`.csv`。
2. 逐个上传或批量上传，观察文件列表出现新文件。
3. 展示文件下载与重复文件检测。

注意事项：

- 压缩包（`.zip` 等）目前不参与 AI 处理；演示前先解压，再上传其中的文件。
- 若一次上传多个文件后部分文件未完成 AI 处理，通常是外部 AI API 限流，等待 1 分钟后再试。

### 3. AI 分类、摘要与敏感检测

1. 等待文件状态变为“处理完成”，查看系统自动生成的分类与标签。
2. 打开文件详情，查看 AI 摘要与要点提取。
3. 上传一份含身份证号、手机号或银行卡号的测试文件，展示敏感内容两级检测结果。
4. 对高敏感文件执行端到端加密，展示加密密钥弹窗与复制操作。

讲解点：文件解析 → AI 打标 → 摘要生成 → 向量索引的异步处理链路；敏感检测使用正则快速过滤 + LLM 深度分析。

### 4. 语义搜索与文档问答

1. 在搜索框输入自然语言问题，例如“项目中关于 Docker 的部分在哪里”。
2. 展示基于 Milvus 向量检索的语义搜索结果。
3. 打开文档问答，单文档提问；再选择多个文件进行跨文档问答。

讲解点：自研 RAG 链路（Embedding → Milvus 向量库 → LLM 生成），以及外部 MaaS 大模型接入方式。

### 5. 内容生成

1. 选择已上传文件，生成摘要或分析报告。
2. 展示输出为纯文字内容，说明信息提取与摘要生成已去除 Markdown 格式干扰。

### 6. 版本对比

1. 对同一文件上传新版本，进入版本历史。
2. 选择两个版本进行对比，展示真实文档内容（中文、英文、代码、符号均可识别）的差异。
3. 说明版本对比当前定位：判断内容是否变化并展示文本差异；纯格式变化不会显示为内容差异。

### 7. 云存储对接

1. 进入云存储对接页面，展示当前已连接的云盘。
2. 上传文件到云盘，或从云盘拉取文件到 NebulaMind。
3. 说明 MinIO/S3 兼容接口与 WebDAV 协议支持。

## 面试讲解建议

- 强调这是一个完整部署到云服务器的作品，不是只有本地可运行的 Demo：前端、后端、AI 服务、数据库、缓存、消息队列、对象存储、向量数据库均在单机 Docker Compose 中运行。
- 讲清楚双服务架构的取舍：Java 负责业务与安全、Python 负责 AI 推理，并用 SSE 流式响应支撑长耗时任务。
- 主动说明 2C4G 低配单机上的运维取舍：小规格机器优先保证核心链路稳定，例如限制外部 AI API 并发、通过 SSE 避免轮询、用 RabbitMQ 解耦文件处理任务。
- 遇到 AI 限流或处理慢时不要回避，直接说明这是外部 API 配额与低配服务器的客观约束，同时展示系统已做的限流与异步处理设计。
- 强调公开仓库已完成敏感信息清理，生产密码通过 `.env` 注入，不在代码与文档中提交。

## 演示环境注意事项

- 不要在大文件上演示 AI 功能，建议单文件不超过 20MB。
- 外部 AI API 一分钟内调用次数有限，连续演示多个文件时注意节奏。
- 演示结束后可清理测试账号与测试文件，保持演示环境干净。
