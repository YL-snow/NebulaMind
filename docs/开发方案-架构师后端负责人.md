# 云盘智能体应用 - 架构师/后端负责人开发方案

> 说明：本文为立项/团队分工阶段的原始方案；最终云存储实现为 S3 兼容存储与 WebDAV 云盘，联通云盘官方 API 未接入。

**创建日期**：2026年7月10日  
**所属团队**：云盘智能体开发团队  
**角色**：架构师/后端负责人

---

## 一、角色定位

**职责领域**：系统架构设计、核心模块开发、云盘API对接、后端服务开发  
**技术栈**：Java/Python, Spring Boot, PostgreSQL, Redis, RabbitMQ, MinIO  
**AI工具策略**：AI辅助架构设计、代码生成、API文档解析

---

## 二、开发任务分解

### 阶段一：需求分析与架构设计（W1-W2）

#### 任务0：API凭证获取（W1优先执行）
- **要做什么**：获取联通云盘API和万悟大模型API的访问凭证
- **怎么做**：
  1. 申请联通云盘API接入，获取AppID、AppSecret
  2. 申请万悟大模型API Key（与大模型工程师协同）
  3. 配置API调用权限和配额
  4. 测试API连通性
- **交付物**：API凭证、接入配置、连通性测试报告

#### 任务1：系统架构设计
- **要做什么**：设计整体系统架构，定义双服务架构和跨语言通信协议
- **怎么做**：
  1. 分析技术方案文档中的架构图和核心模块设计
  2. 使用AI辅助生成架构设计文档，包括组件图、时序图、数据流图
  3. 设计双服务架构：
     - **Java单体后端**：文件管理、用户认证授权、安全管控、协作功能（Spring Boot）
     - **Python AI服务**：文件理解、语义检索、内容生成、RAG问答（LangChain）
  4. 定义跨语言通信协议：REST API + JSON格式，统一API规范
  5. 定义消息队列用途：文件上传异步处理（架构师发送→大模型工程师消费）
  6. 确定技术选型并编写技术选型文档
- **交付物**：系统架构设计文档、双服务架构方案、API规范文档、技术选型文档

#### 任务2：数据库设计
- **要做什么**：设计PostgreSQL数据库表结构和索引策略，包括全文检索索引
- **怎么做**：
  1. 根据技术方案中的数据模型设计数据库表
  2. 设计文件表、用户表、权限表、版本表、日志表
  3. 设计索引策略优化查询性能（包括BM25全文检索索引，供大模型工程师的语义检索模块使用）
  4. 设计文件内容表（用于存储文件解析后的文本内容，供全文检索和RAG使用）
  5. 使用AI辅助生成ER图和DDL脚本
- **交付物**：数据库ER图、DDL脚本、索引策略文档、全文检索索引配置

#### 任务3：云盘API对接方案设计
- **要做什么**：设计联通云盘API和主流云存储协议的对接方案，产出API接口契约文档
- **怎么做**：
  1. 分析联通云盘API文档，设计认证流程和接口封装
  2. 设计WebDAV/S3协议兼容层架构
  3. 设计文件同步机制（增量同步+Webhook）
  4. 设计后端API接口规范，产出Swagger/OpenAPI接口文档（供前端Mock开发）
  5. 使用AI辅助解析API文档并生成接口调用代码
- **交付物**：云盘API对接设计文档、协议兼容层设计、Swagger/OpenAPI接口文档

### 阶段二：核心开发（W3-W4）

#### 任务4：后端服务框架搭建
- **要做什么**：搭建Spring Boot后端服务框架，集成Spring Security基础框架和实时通信
- **怎么做**：
  1. 创建Spring Boot项目，配置依赖（Spring Security, Spring Data JPA, Spring AMQP）
  2. 集成Spring Security框架，配置安全过滤器链
  3. 预留JWT认证和RBAC授权的扩展接口（由安全工程师实现具体逻辑）
  4. 配置Redis缓存和RabbitMQ消息队列
  5. 集成WebSocket/SSE实时通信（用于AI处理进度推送和流式问答响应）
  6. 实现全局异常处理和日志记录
  7. 使用AI辅助生成项目骨架代码
- **交付物**：后端服务基础框架、Spring Security集成框架、安全扩展接口、实时通信模块

#### 任务5：文件管理模块开发
- **要做什么**：实现文件上传、下载、管理的核心API，通过消息队列触发AI处理
- **怎么做**：
  1. 实现文件上传接口（支持分片上传）
  2. 实现文件存储到MinIO，记录元数据到PostgreSQL
  3. 实现文件列表、详情、删除接口
  4. 实现文件哈希计算（SHA-256）用于重复检测
  5. 实现异步处理文件（通过RabbitMQ发送消息，消息体包含文件ID、路径、用户ID）
  6. 实现文件删除时发送消息到RabbitMQ，通知大模型工程师删除向量索引
  7. 实现文件处理回调接口（接收大模型工程师处理完成的通知，更新文件状态）
- **交付物**：文件管理API（CRUD）、MinIO存储集成、消息队列发送机制、回调接口

#### 任务6：云盘API对接实现
- **要做什么**：实现联通云盘API和WebDAV/S3协议对接
- **怎么做**：
  1. 实现联通云盘OAuth2认证流程
  2. 封装云盘文件列表、上传、下载API
  3. 实现文件增量同步机制
  4. 实现WebDAV协议兼容层（支持PROPFIND, GET, PUT, DELETE）
  5. 实现S3协议兼容层（支持ListObjects, GetObject, PutObject）
- **交付物**：云盘API客户端、协议兼容层、文件同步服务

### 阶段三：功能开发（W5-W6）

#### 任务7：后端API完整实现
- **要做什么**：实现所有业务API接口，AI相关接口调用大模型工程师的Python API
- **怎么做**：
  1. 实现智能分类接口（路由层，调用Python AI服务的分类API）
  2. 实现重复检测接口（基于文件哈希和内容相似度，本地逻辑）
  3. 实现语义搜索接口（路由层，调用Python AI服务的检索API）
  4. 实现文档问答接口（路由层，调用Python AI服务的RAG API）
  5. 实现内容生成接口（路由层，调用Python AI服务的生成API：摘要、报告、PPT）
  6. 实现文件处理回调接口（接收大模型工程师处理完成的回调通知）
  7. 使用AI辅助生成API实现代码和单元测试
- **交付物**：完整后端API实现（路由层+本地逻辑）、单元测试用例

#### 任务8：架构优化与性能调优
- **要做什么**：优化系统架构和性能
- **怎么做**：
  1. 实现数据库读写分离（如果需要）
  2. 优化查询性能（索引优化、查询缓存）
  3. 实现接口限流和熔断（使用Sentinel/Hystrix）
  4. 优化文件上传下载速度（CDN加速、分片传输）
- **交付物**：性能优化报告、限流熔断配置

### 阶段四：集成测试与演示（W7-W8）

#### 任务9：系统集成
- **要做什么**：整合所有模块，确保端到端流程畅通
- **怎么做**：
  1. 整合前端、后端、AI服务、数据库
  2. 调试接口联调问题
  3. 测试文件上传→AI处理→向量索引→检索的完整流程
- **交付物**：系统集成测试报告

#### 任务10：技术文档编写
- **要做什么**：编写完整的技术文档和接口文档
- **怎么做**：
  1. 编写后端API接口文档（使用Swagger/OpenAPI）
  2. 编写系统架构文档
  3. 编写部署指南
  4. 使用AI辅助生成文档内容
- **交付物**：技术方案文档、API接口文档、部署指南

## 四、协作与沟通机制

### 4.1 每日工作流程
```
09:00-09:15  站会（AI辅助生成日报）
09:15-12:00  上午开发（AI辅助编码）
12:00-13:30  午休
13:30-18:00  下午开发（AI辅助调试）
18:00-18:30  每日总结（AI辅助生成周报）
```

### 4.2 代码提交规范
| 类型 | 前缀 | 示例 |
|-----|------|-----|
| 新增功能 | feat | feat(upload): 实现文件分片上传 |
| 修复Bug | fix | fix(search): 修复搜索结果排序问题 |
| 代码优化 | refactor | refactor(api): 重构API响应格式 |
| 文档更新 | docs | docs(api): 更新API接口文档 |
| 测试用例 | test | test(file): 添加文件管理测试用例 |
| 配置变更 | chore | chore(k8s): 更新Deployment配置 |

### 4.3 评审机制
- **PR审查**：必须经过AI预审查+至少1人人工审查
- **代码质量门**：测试覆盖率>80%，无严重代码异味
- **安全审查**：涉及安全的代码必须经过安全工程师审查
